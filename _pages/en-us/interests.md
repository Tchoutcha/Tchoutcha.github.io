### Kubernetes

What I love about Kubernetes is its declarative model: you describe the state you want, and controllers keep working until the cluster matches it.
A crashed container is restarted, a lost node is replaced, without anyone stepping in.

### Containers: Docker and Podman

A container is not a small virtual machine: it is a normal Linux process, isolated with kernel features such as namespaces and cgroups.
I like Podman for its daemonless and rootless design, and I enjoy comparing how each tool does the same job differently.

### Cloud and serverless

Serverless lets developers run code without managing any server: the platform starts it on demand, scales it, and stops it when nobody uses it.
I am curious about everything that happens behind that simplicity.

### Edge computing

Running services close to where data is produced, on small and cheap devices, instead of sending everything to a distant data center.

### Energy

Data centers use more and more electricity. I care about making infrastructure do the same work with less energy.

### What I am learning right now

- Kubernetes certifications: **CKA** and **CKAD**
- Observability: **Prometheus, Grafana, Loki, OpenTelemetry**
